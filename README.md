## Menu Kali
Menu Kali é uma ferramenta de segurança desenvolvida em Python com o objetivo de auxiliar usuários na análise e organização do seu computador. O sistema reúne recursos para criação de senhas seguras, avaliação de vulnerabilidades básicas e monitoramento de informações do sistema.

O projeto foi desenvolvido utilizando Programação Orientada a Objetos (POO), explorando conceitos como classes, métodos, organização de código e uso de bibliotecas nativas do Python.
